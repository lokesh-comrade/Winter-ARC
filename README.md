## 🎯 Features
* **Custom Protocol Setup:** Configure your own challenge name, date timeline, and non-negotiable daily habits.
* **✨ AI Auto-Generator:** Instantly populate a high-performance routine if you're ready to lock in without manual typing.
* **🔒 Anti-Cheat Lockout Security:** Past days are automatically secured against tampering so historical logs remain 100% honest.
* **📊 Analytics & Matrix Grids:** Visual contribution heatmaps and Day-by-Task breakdown grids.
* **⚡ 100% Offline & Serverless:** Runs directly in your phone browser via local storage with zero server downtime issues.

## 📱 How to Install on Mobile (One-Tap App)
1. Tap the **Launch Web App** button above from your phone (iOS Safari or Android Chrome).
2. **iPhone (Safari):** Tap the **Share** button $\rightarrow$ Select **"Add to Home Screen"**.
3. **Android (Chrome):** Tap the **3 dots menu** $\rightarrow$ Select **"Add to Home screen"** or **"Install App"**.
4. It launches full-screen like a native application!
